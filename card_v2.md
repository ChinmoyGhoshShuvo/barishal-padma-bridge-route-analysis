**Title:** Barishal to Padma Bridge Route Selection (GIS Network Analysis + AHP)

**Summary:** Using ArcGIS network analysis, this project compared the existing, shortest and a potential route from Barishal to the Padma Bridge link road by length, time, cost and road class. It then ranked the three with a five-factor AHP (CR 5.4%). The existing route scored highest (0.768) because it is the only one built mainly on trunk roads.
